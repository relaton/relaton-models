= Relaton Guobiao (GB) bibliographic model

Bibliographic model for Guobiao (GB) — the flavour overlay of the shared RelBib
BibliographicItem model.

This directory is the `gb` flavour of the unified
https://github.com/relaton/relaton-models[relaton-models] repository
(formerly the standalone relaton-model-gb repository; merged with its
git history on 2026-08-18).

== Layout

* `models/`, `views/` — LutaML model sources
* `images/` — generated model diagrams, committed
* `grammars/relaton-gb.rnc` — the flavour grammar overlay

Diagrams regenerate via the root `Makefile`; the overlay is consumed by
the Metanorma grammar hub
(https://github.com/metanorma/standoc-models[standoc-models]).
