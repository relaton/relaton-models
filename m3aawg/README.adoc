= Relaton M3AAWG bibliographic model

Bibliographic model for M3AAWG — the flavour overlay of the shared RelBib
BibliographicItem model.

This directory is the `m3aawg` flavour of the unified
https://github.com/relaton/relaton-models[relaton-models] repository
(formerly the standalone relaton-model-m3aawg repository; merged with its
git history on 2026-08-18).

== Layout

* `models/`, `views/` — LutaML model sources
* `images/` — generated model diagrams, committed
* `grammars/relaton-m3aawg.rnc` — the flavour grammar overlay

Diagrams regenerate via the root `Rakefile` (`bundle exec rake render`); the overlay is consumed by
the Metanorma grammar hub
(https://github.com/metanorma/standoc-models[standoc-models]).
